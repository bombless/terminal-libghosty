# terminal-libghosty

A Windows SSH connection manager with a graphical profile picker and an SSH terminal launcher. See [desktop UI instructions](docs/desktop-ui.md).

The GUI Connect action forks the same `terminal-libghosty.exe` with the private `--server` mode. The parent remains the profile-manager client; the child owns the Direct2D terminal surface, SSH connection, ConPTY session, and Ghostty rendering, embedded in the parent's window. The child is tied to the parent process lifetime and is terminated on disconnect. There is one application executable, not a separately built `terminal-host.exe`. SSH argv comes from `internal/ssh.BuildArgs()` with strict host-key verification. This is an initial embedded renderer: IME, clipboard, mouse reporting/selection, font/DPI handling, and full style fidelity still need work before production acceptance. See [implementation status](docs/implementation-status.md).

The production Go application uses the standard Go toolchain with cgo disabled (`CGO_ENABLED=0`). ConPTY process management and the Ghostty host adapter are implemented in Go; the official `ghostty-vt.dll` remains the VT parser/render-state engine and is packaged beside the executables. The original `native/` C implementation is retained as the compatibility reference and can still be built/run through CMake for regression comparison; the Go application does not load `terminal_libghosty_session.dll`. See [native build notes](native/README.md).
