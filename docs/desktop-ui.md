# Windows desktop UI

Run `desktop/Launch Terminal Libghosty.bat` or `dist/terminal-libghosty.exe` to open the graphical SSH connection manager. Add and save `user@host` profiles, optional port overrides and identity files. Profiles are stored in `%APPDATA%\TerminalLibghosty\connections.json`. Connect launches an embedded hardware-accelerated Direct2D terminal surface (`internal/d2d`, `internal/gui`). The terminal calls `internal/terminal.StartSSH()` and uses the system OpenSSH client through ConPTY; strict host-key checking remains enabled. Use **BACK / DISCONNECT** to close the SSH session and return to profile editing.

The application is written in Go and controlled entirely by Golang with Direct2D/DirectWrite rendering (no PowerShell or WinForms dependencies). The native `terminal_libghosty_session.dll` and `ghostty-vt.dll` must exist in `build/native-local` (or in the application directory / `TERMINAL_LIBGHOSTY_NATIVE_DIR`). The Direct2D renderer consumes Ghostty cell snapshots, including colors, selection and cursor, and supports keyboard input and dynamic resize.
