# Windows desktop UI

Run `desktop/Launch Terminal Libghosty.bat` to open the graphical SSH connection manager. Add and save `user@host` profiles, optional port overrides and identity files. Profiles are stored in `%APPDATA%\TerminalLibghosty\connections.json`. Connect creates a Win32 child terminal surface inside the right-hand profile panel. The child host calls `internal/terminal.StartSSH()` and uses the system OpenSSH client through ConPTY; strict host-key checking remains enabled. Use **BACK / DISCONNECT** to close the SSH session and return to profile editing.

The embedded host executable is built on first Connect (Go toolchain required) as `dist/terminal-host.exe`; the native `terminal_libghosty_session.dll` and `ghostty-vt.dll` must already exist in `build/native-local` (or update the script's native path to your build output). The Win32 renderer consumes Ghostty cell snapshots, including colors, selection and cursor, and supports basic text/arrow-key input and resize. IME, clipboard, mouse reporting/selection, font/DPI scaling, and full VT style handling remain incomplete; this is an initial integration, not yet a fully polished terminal. The Go wrapper uses the standard Windows DLL interface; gccgo is not required.
