# Windows desktop UI

Run `desktop/Launch Terminal Libghosty.bat` or `dist/terminal-libghosty.exe` to open the graphical connection manager. Add and save `user@host` profiles, optional port overrides and identity files. Profiles are stored in `%APPDATA%\TerminalLibghosty\connections.json`. The right-hand side is a tabbed workspace: the **SSH CONFIG** tab edits the selected profile and stays available while sessions run. **NEW SSH** switches to that tab (and clears the form when it is already active), **NEW PWSH** opens a new local PowerShell 7 tab, and double-clicking a saved profile opens a new SSH tab from its stored settings; opening the same profile again creates another session tab. Each session tab has a **×** close button. Use **HIDE LIST** in the top-right corner (or press **F9**) to collapse or expand the left connection list; collapsing gives the workspace the full window width. Sessions run in an embedded hardware-accelerated Direct2D terminal surface (`internal/d2d`, `internal/gui`): SSH tabs call `internal/terminal.StartSSH()` and use the system OpenSSH client through the Go ConPTY manager with strict host-key checking, while PowerShell tabs call `internal/terminal.StartPowerShell()` to run `pwsh.exe`. `terminal-libghosty.exe --shell pwsh` starts with a PowerShell tab directly.

The production application statically links `libghostty-vt` through cgo, so the release executable has no `ghostty-vt.dll` dependency. `build.ps1` builds `ghostty-vt-static.lib` with Zig 0.17 and then builds with `CGO_ENABLED=1` and Zig as the C compiler. For development with cgo disabled, the host falls back to loading `ghostty-vt.dll`; place it beside the application or set `GHOSTTY_VT_DLL` / `TERMINAL_LIBGHOSTY_NATIVE_DIR`. ConPTY process management, Ghostty host integration and Session composition are implemented in Go. The project-owned `terminal_libghosty_session.dll` is not used by the Go application. The original C implementation remains available as a compatibility reference and can still be built with CMake.

The Direct2D renderer consumes Ghostty cell snapshots, including colors, selection and cursor, and supports keyboard input and dynamic resize.
